# pairwise-gi-probe

室内外过渡时墙角漏光、动态物体发黑、探头更新时间跳：光照探头按网格中心采样；DDGI 探针更新轮转和相机移动不同步；探针法线偏移用固定值；遮挡射线步长按探针间距；辐射度历史按帧数而不是时间累积；探针边界夹取把墙外样本拉进来；动态物体只采样静态探针；天空光和自发光探针混用；探针插值权重在网格边界不归一；多场景切换没清探针历史。render/gi_probe.py 是核心，tests/test_gi_probe.py 15个红。要修的是：表面采样偏移；相机优先更新；自适应法线偏移；射线按场景尺度；时间累积；边界探针剔除；动态探针组；光照类型分层；插值归一；切换清历史。
